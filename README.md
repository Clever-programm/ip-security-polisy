# build-ipsec

PowerShell-скрипт, который собирает политику IPsec для блокировки сайтов из обычного текстового списка доменов и экспортирует её в файл `.ipsec`. Файл в таком же формате получается в оснастке «Локальная политика безопасности» (`secpol.msc`) через «Экспорт политик».

Полученный `.ipsec` можно импортировать на любой машине с Windows и назначить. После этого трафик к адресам из списка будет блокироваться на уровне сетевого стека, без сторонних программ.

## Структура репозитория

```
.
├── build-ipsec.ps1        # сам скрипт
├── domains-example.txt    # пример входного списка
└── README.md
```

## Требования

- Windows с `netsh ipsec static` (Windows 7 / 10 / 11, Windows Server)
- Windows PowerShell 5.1 или PowerShell 7
- Права администратора
- Доступ к DNS: домены резолвятся в IP в момент запуска

## Формат входного файла

Одна запись на строку, кодировка UTF-8.

```text
# комментарий: всё после # игнорируется
example.com
https://www.example.org/some/page   # схема, путь и порт отбрасываются
мойгород.рус                        # кириллические домены переводятся в punycode
aliexpress.ru NS1                   # всё после первого пробела игнорируется
185.62.202.2                        # одиночный IP
10.20.0.0/16                        # подсеть
```

Дубликаты и пустые строки отбрасываются. Некорректные строки пропускаются и выводятся в отчёте в конце работы.

## Использование

Запустите PowerShell **от имени администратора**:

```powershell
powershell -ExecutionPolicy Bypass -File .\build-ipsec.ps1 -InputFile .\domains.txt
```

Результат по умолчанию сохраняется в `.\blok-ip-new.ipsec`. После экспорта скрипт удаляет созданную политику из локального хранилища, так что на машине, где он запускался, ничего не меняется.

### Параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| `-InputFile` | — (обязательный) | Путь к списку доменов |
| `-OutputFile` | `.\blok-ip-new.ipsec` | Куда сохранить результат |
| `-PolicyName` | `Блокировка сайтов` | Имя политики IPsec |
| `-Description` | `Блокирует указанные сайты по IP или адресам подсетей` | Описание политики |
| `-FilterListName` | `Нежелательные сайты` | Имя списка фильтров |
| `-FilterActionName` | `Блокировка сайта` | Имя действия фильтра |
| `-RuleName` | `Блокировка нежелательных сайтов` | Имя правила |
| `-KeepInStore` | выкл. | Оставить политику в локальном хранилище (не назначенной) |

Пример с собственными именами:

```powershell
.\build-ipsec.ps1 -InputFile .\list.txt -OutputFile C:\temp\school.ipsec -PolicyName "Школьный фильтр"
```

## Как применить полученный файл

**Через GUI.** Откройте `secpol.msc` → «Политики IP-безопасности на локальном компьютере» → ПКМ → «Все задачи» → «Импорт политик…». Затем ПКМ по импортированной политике → «Назначить».

**Через командную строку** (от администратора):

```bat
netsh ipsec static importpolicy file=C:\path\blok-ip-new.ipsec
netsh ipsec static set policy name="Блокировка сайтов" assign=y
```

Снять блокировку можно так:

```bat
netsh ipsec static set policy name="Блокировка сайтов" assign=n
```

В доменной сети ту же политику можно распространить через групповые политики (GPO).

## Ограничения

- **IPsec фильтрует по IP, а не по доменам.** Домен резолвится один раз, при запуске скрипта. Сайты на CDN (Akamai, Cloudflare, AWS, Google) часто меняют адреса. Из-за этого блокировка со временем может перестать работать или начать задевать посторонние сайты на тех же IP. Список стоит периодически пересобирать. Если блокировать нужно именно по именам, лучше подойдут `hosts`, DNS-фильтр или прокси.
- **`exportpolicy` выгружает все IPsec-политики из локального хранилища.** Если на машине уже есть другие политики, они тоже попадут в файл. Собирать лучше на чистой машине или в виртуалке.
- **Скорость.** Каждая запись означает отдельный вызов `netsh` и DNS-запрос, поэтому список из нескольких сотен доменов обрабатывается одну-две минуты.
- Домены, которые не удалось отрезолвить, пропускаются и перечисляются в итоговом отчёте.
- Скрипт для PowerShell 5.1 сохранён в UTF-8 **с BOM**. Без BOM кириллица в именах политики превратится в кракозябры, учитывайте это при редактировании.
